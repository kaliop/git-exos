# Site Web d'Exercice Git

Ce repository contient un site web simple créé pour une formation Git. Il permet aux stagiaires de pratiquer les commandes Git sur un projet concret.

## Contenu

- **index.html** : Page principale du site
- **style.css** : Feuille de style CSS avec design responsive
- **README.md** : Ce fichier de documentation

## Fonctionnalités

- Design responsive (mobile-friendly)
- Navigation avec ancres
- Sections : Accueil, À propos, Services, Contact
- Footer informatif

## Utilisation pour la formation

Ce repository est conçu pour être utilisé dans le cadre d'exercices Git. L'historique des commits montre une progression logique de développement :

1. Structure HTML de base
2. Ajout du CSS
3. Contenu principal
4. Améliorations du design
